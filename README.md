# Event-deposit toolkit

Python workflow for separating flood-induced from earthquake-triggered event
beds in lake sediment cores, using grain-size statistics from laser
diffraction combined with XRF elemental data.

Built alongside my M.S. thesis work on sediment cores from **Lake Lachuá,
Guatemala** (Missouri University of Science and Technology, advised by
Dr. Jonathan Obrist-Farner).

> **On the data.** The core measurements behind my thesis are unpublished and
> belong to the lab, so nothing real is included here. Everything runs on a
> synthetic core generated by `src/synthetic_core.py`, built to reproduce the
> structure of the real dataset — laser-diffraction distributions, XRF counts,
> an age-depth model, and event beds tied to a historical catalogue. The
> methods are the point; the numbers are stand-ins.

## The problem

A turbidite in a lake core tells you something happened. It does not tell you
*what*. A tropical cyclone dumping catchment sediment into the lake and an
earthquake shaking the delta front both produce a graded bed sitting in fine
background mud. Distinguishing them matters, because one is a flood record and
the other is a paleoseismic record, and hazard assessments built on a
misidentified bed are wrong in an expensive direction.

## What the workflow finds

Running the demo on the synthetic core gives effect sizes between the two
event types:

| Variable | Flood beds | Seismic turbidites | Cohen's *d* |
|---|---|---|---|
| D50 (µm) | 15.9 | 23.7 | 0.46 — weak |
| Sorting (φ) | 1.04 | 2.04 | **4.20 — strong** |
| Skewness | −0.00 | 0.09 | 1.31 — moderate |
| Sand (%) | 4.2 | 19.2 | 1.08 — moderate |
| Ti/Ca | 0.154 | 0.048 | **2.29 — strong** |

Median grain size, the single most commonly reported grain-size number, is the
*weakest* discriminant in the set. Sorting and the Ti/Ca terrigenous proxy
carry the separation. Plotted against each other they resolve three
non-overlapping clusters — background mud, flood beds, seismic turbidites.

The geochemical logic is specific to a karst lake: **Ti** is detrital, delivered
from the catchment, so it spikes when a storm erodes the watershed. **Ca** is
endogenic carbonate produced within the lake. A seismic turbidite remobilises
material already sitting on the lake floor, so it stays carbonate-rich and
Ti/Ca hardly moves; a flood bed dilutes the carbonate with fresh terrigenous
input and Ti/Ca jumps by a factor of three.

## Usage

```bash
pip install -r requirements.txt
python run_demo.py
```

Writes CSVs to `data/` and figures to `figures/`.

To run the statistics on your own Mastersizer export:

```python
import sys; sys.path.insert(0, "src")
import grainsize

bins_um, volumes, meta = grainsize.read_mastersizer_csv("your_export.csv")
stats = grainsize.analyse_core(bins_um, volumes, meta["depth_cm"])
```

`read_mastersizer_csv` assumes size-bin diameters as column headers and one row
per measurement. Malvern Xplorer's export layout is configurable, so check it
against your own file before trusting it.

## What's implemented

**`src/grainsize.py`** — Folk & Ward (1957) graphical statistics: mean, sorting
(inclusive graphic standard deviation), skewness, graphic kurtosis, all computed
in φ from interpolated cumulative curves. Plus D10/D50/D90, Udden-Wentworth size
fractions, and the verbal sorting classification.

**`src/synthetic_core.py`** — Core generator. Event beds are instantaneous
deposits, so the age model is built on an event-free depth scale with bed
thicknesses removed, which is what you would do before radiometric dating a real
core. Flood beds are given inverse-to-normal grading; seismic turbidites get a
polymodal coarse base with simple normal grading.

**`src/plots.py`** — Downcore logs, distribution curves, discrimination plots.

## Caveats

The discrimination criteria encoded in the generator are simplified, and in the
literature they are contested rather than settled. Inverse-to-normal grading is
a reasonably well-supported hyperpycnite signature, but real flood beds are
often amalgamated, real seismic turbidites can be stacked or multi-pulsed, and
catchments with different lithology behave differently. Clean separation on
synthetic data means the code works, not that nature cooperates.
